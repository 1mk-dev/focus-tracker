# focus-tracker
A lightweight studying/working app built with Python + Tkinter for tracking focus time data.

## Features
- Named session tracking with start / pause / resume / finish
- Automatic session logging to CSV in format (TimestampEnd,SessionName,TimeSecond,PauseTimeSecond)
- Fully customizable colour palettes / images with theme saving
- Minimizes to system tray to stop distractions
- Stores study session names alongside all settings in .JSON format

## Download
Latest version from [Releases page](https://github.com/1mk-dev/FocusTracker/releases). No Python required, just unzip and run "FocusTracker.exe".

## Data Analysis
- CSV allows for easy exporting to Excel or any software of your choice
